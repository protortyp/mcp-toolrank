# Name-weighted BM25 retrieval

Python ToolSelector adds BM25 to the embedding cosine and TF-IDF hybrid with `bm25_weight=0.15` and `lexical_weight=0.4`. The sparse CPU index uses tool descriptions and repeats recognizable names three times. BM25 scores are normalized by each request’s maximum.

```python
from sentence_transformers import SentenceTransformer
from toolrank.selector import ToolSelector

model = SentenceTransformer("christianengel/mcp-toolrank-33m")
selector = ToolSelector(
    model,
    [{"name": "find_events", "description": "Search the calendar for scheduled meetings"}],
    lexical_weight=0.4,
    bm25_weight=0.15,
)
matches = selector.rank("Find my next calendar meeting", k=3)
```

Both weights default to zero. `min_score` and `Match.cosine` use embedding cosine. Calibrate rejection on your catalog.

Ranking metrics compare identical checkpoints and inputs on answerable requests. They exclude 91 ETOM and 24 API no-match requests. Rejection and execution remain unevaluated.

We chose 0.15 on 872 requests from providers outside training, using 34 tools with and without 263 distractors. We evaluated frozen holdouts and reran them with the released scorer. [Benchmark inputs](MODERN_MCP.md#reproduction) · [Raw metrics](../results/bm25-tool-selection.json)
