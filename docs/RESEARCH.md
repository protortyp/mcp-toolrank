# Research log

## 2026-11-20

- Reviewed ToolRet's ACL paper and official FlagEmbedding recipe. The paper describes 7,615 tasks, 43,215 tools, and three categories. The current pinned release has 7,961 queries and 44,453 tool IDs. The authors also define Completeness@K, which requires retrieving every positive. Their training data aggregates ToolACE, ToolBench and APIGen with NV-Embed-mined negatives. Source families recur across the paper's training and evaluation descriptions, so row-level deduplication would not establish unseen-family performance. [ACL paper](https://aclanthology.org/2025.findings-acl.1258/) · [ToolRet implementation inspected](https://github.com/mangopy/tool-retrieval-benchmark/tree/c4181d914a227134705ecb6bab13fbd92ccd2938)
- Inspected MTEB's integration and revision `76d45e560059754e289ea202462865a585679619`. MTEB exposes 35 English subsets, strips the supplied task instruction for ToolRetrieval, and keeps it for ToolRetrievalInstruction. The integration defines a generic task prompt and nDCG@10 as its primary score. Its repeated per-subset corpus packaging is about 1.56M document rows. This pilot shares the upstream catalog across its queries and uses model-card prompts and query-weighted aggregation. [MTEB integration](https://github.com/embeddings-benchmark/mteb/pull/5410) · [Pinned dataset](https://huggingface.co/datasets/mteb/ToolRetrieval/tree/76d45e560059754e289ea202462865a585679619)
- Reviewed Tool-REX's ICLR paper, released evaluation code, and checkpoints. The project expands tool documents with function, use, limitations, and tags. Tool-Embed starts from Qwen3 Embedding and uses InfoNCE over approximately 50K pairs. The Web training sources include APIGen and ToolBench. Code and Customized are stronger out-of-domain comparisons in that study. Tool-Rank is a second-stage reranker and has a different inference budget. Our direct dense benchmark uses the published Tool-Embed-0.6B card prompt, original ToolRet documents, and 512-token truncation. Its measurements are specific to those choices. [ICLR paper](https://proceedings.iclr.cc/paper_files/paper/2026/hash/e54a9889f1048526365ed8fb56c8c8cd-Abstract-Conference.html) · [Tool-REX implementation inspected](https://github.com/EIT-NLP/Tool-REX/tree/7ac8eac8215efc4d743e0b0247a3b94577d02d28) · [Checkpoint](https://huggingface.co/Lux1997/Tool-Embed-0.6B)
- Chose ToolScout as the size-matched specialized reference. Its card measures against 36 tools and reports that its final weights were retrained on all 36. Its original held-out numbers therefore cannot validate the released weights on those same tools. Locally mirrored its newer module metadata to the pinned library's built-ins. [ToolScout model card](https://huggingface.co/nuhmanpk/toolscout-bge-small)
- Froze original train, development and test files before fitting. Measured zero cross-split overlaps in family, tool ID, tool name and normalized request. Original training queries and descriptions also had zero exact overlaps and zero normalized character-four-gram cosine matches at or above 0.8 against ToolRet. Peak similarities were 0.463 for queries and 0.574 for tool text. Differences in tool serialization limit that lexical check. Public-model pretraining and undisclosed benchmark exposure remain unverified. [Audit output](../results/audit.json)
- Ran the local three-recipe, three-seed contrastive pilot. Development selected in-batch negatives at 2e-5 with temperature 0.05 and batch 16. This comparison changes several factors jointly. It does not isolate which factor drove the result. [Run records](../results/training) · [Selection](../results/selection.json)
